# Security policy

## Prototype boundary

Decentralert is a research and demonstration prototype. It is not connected to 112, NL-Alert, or any live emergency service. Do not use the repository, issue tracker, or demo to report an emergency.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature instead of opening a public issue. Include the affected component, reproduction steps, impact, and any suggested mitigation.

Do not include real medical records, precise personal locations, credentials, access tokens, or other sensitive data in a report.

## Supported version

Only the latest commit on `main` and the most recent judge-preview release are currently maintained.

## Production warning

Production deployment would require, at minimum, authority-approved integrations, independent security assessment, a DPIA, scoped access controls, audited responder verification, encrypted evidence storage, an approved retention schedule, and jurisdiction-specific legal review.
